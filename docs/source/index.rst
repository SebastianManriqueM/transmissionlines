TransmissionLines
=================

``transmissionlines`` is an unreleased Python package for typed transmission-line
data, Julia-parity electrical parameters, and positive-sequence St. Clair
loadability curves. It requires Python 3.12 or newer. There is no published
package release yet.

Start with :doc:`installation` and the :doc:`quickstart`. The rest of the site
covers the data model, calculation assumptions, user workflows, and generated
API reference.

.. warning::

   Electrical calculations implement the assumptions documented here and in
   the source. They are not a substitute for an independent engineering review
   or validation against applicable standards before production use.
